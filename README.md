# 黑潮号 · 船长的海盗之旅

双击 **开始游戏.cmd**，浏览器打开后点「开始游戏」。不用手动输入 Node 命令，当前电脑可以直接运行。

双击 **查看船模.cmd** 可以单独欣赏整船，拖动旋转、滚轮靠近，并切换甲板、艉台、船长室、牢房、住舱、厨房、货舱和小艇视角。查看页支持展开下帆、暮色、船底观察和导出 GLB。

双击 **结束游戏.cmd** 关闭后台服务。

从 GitHub 首次下载到新电脑时，先安装 Node.js 18 或更高版本，在项目目录执行一次 `npm install`，然后双击上述入口。使用 pnpm 时可执行 `pnpm install --frozen-lockfile`。依赖文件夹不随仓库上传。

## 游戏操作

| 操作 | 按键 |
| --- | --- |
| 步行、游泳、划艇 | WASD 或方向键 |
| 转头 | 直接移动鼠标；开始游戏后锁定鼠标 |
| 奔跑 / 蹲下 | Ctrl / Shift |
| 跳跃、爬梯松手、游泳上浮 | 空格 |
| 互动 | 准星瞄准操作部位，左键；低处的拉环先蹲下 |
| 背包 | E；左键取放、右键拆分、Shift+左键向打开的箱子转移 |
| 快捷物品 / 空手 / 丢一件 | 1–9 或滚轮 / X / Q |
| 手持物辅助操作 | 右键举望远镜、切换提灯、进入绳卷放置 |
| 航海图 | M |
| 船模点选水手命令 | B |
| 视野与灵敏度 | 暂停面板的设置滑块 |
| 视角回正 | C |
| 暂停、重新开始 | Esc |

- **船长室**：两侧艉梯中间的矮门，瞄准把手左键开门，再从门洞中心正常走入。人物保持 1.62 米，眼高 1.43 米。
- **水手舱 / 货舱**：蹲下瞄准拉环，左键打开；再瞄准梯级左键抓住。W 上爬、S 下爬，尽头自动跨出，空格会松手下落。
- **收锚**：瞄准绞车制动杆左键压下，再按住木推杆收锚。松开停止；抬起制动杆放锚。
- **掌舵**：走上艉梯，从轮后瞄准轮圈左键握住。W/S 推进、A/D 转向，左键松手，鼠标仍可转头。
- **救生艇**：左舷艉部吊艇装置，瞄准吊索操作处左键解固定索，再左键下放。W/S 划桨、A/D 转向，左键离艇。
- **爬桅 / 返回船上**：瞄准真实梯级左键抓握，手脚沿梯道攀爬；海里可抓船侧梯和码头梯。
- **水手**：按 B 打开船务台，拖动旋转船模，点船锚、帆编号或瞭望塔，再选择自动分配或指定水手并下令。三名水手会从下舱走到岗位，爬梯、执行任务，再回舱；站岗持续到撤回。名单会显示忙碌、通道受阻和返舱状态。请给水手留出通道，受阻时他们会等候。
- **背包与箱子**：船长室箱有提灯与绳卷，货舱箱有备用绳，主桅顶有望远镜。海图为随身关键物品，不能丢弃。库存与航程保存在当前浏览器本机；重开从主甲板安全位置继续。

开局及恢复航程均为空手，海图留在快捷栏，按 1 可装备、X 收起，也可直接按 M 查看。第一人称使用方块手，低头能看见裤腿和靴子。

打开背包、海图、船务或暂停面板会停止模拟并释放鼠标，关闭后点击「继续游戏」；成功发令会直接恢复游戏。内嵌浏览器无法锁定时，可点「使用兼容控制」，改用右键拖动观察。语音下令由浏览器提供，仅点击语音按钮后申请麦克风权限，不支持时用船模点选。

## 船模

按 `海盗船_Three.js建模描述.md` 制作：32 米曲面木船壳、8.5 米宽、3.5 米吃水；主甲板 2.4 米、艉甲板 4.55 米、前甲板 3.1 米；三桅十一帆、十门空心舷炮、双木横杆锚、水平木绞车、五扇艉窗和 4.8 米小艇。

内舱包括船长室、27 张吊床、20 个水桶、厨房、维修用品、四牢房、货舱、火药储藏区和舱底结构。全船十九件灯具。帆的满帆、缩帆与收帆使用实际形变、布束与绑扎，固定边、边绳和操索保持连接。

「查看船模.cmd」中的导出按钮可生成当前整船的独立 GLB，可导入支持 glTF 的软件；游戏中的门、锚、船舵、帆装和吊艇控制保留在 Three.js 源码中。旧模型快照 `artifacts/model-20261008-export/黑潮号.glb` 与历史备份仅保留在本地，不随 Git 仓库上传。

## 本地验证

本项目直接运行浏览器 ES Modules，依赖 Three.js 0.180.0、Rapier 0.21.0，没有额外打包步骤。开发入口 `node server.mjs`，默认 http://127.0.0.1:5173/。

- `node check.mjs`：模型几何、尺寸、库存/存档、三维碰撞和人体接触检查。
- `node interaction-playtest.mjs`：本机 Playwright/Edge 驱动鼠标锁定、准星左键与面板输入。
- `node crew-check.mjs`：水手真实路线、十一面帆、三座瞭望塔、取消与并发命令检查。
- `node crew-ui-check.mjs`：船模15个目标点选、忙碌提示、单塔召回、语音退出和快捷栏布局检查；语音识别接口使用模拟器，不能代替麦克风实测。
- `node playtest.mjs`：上一版船模交付的输入记录脚本，原 E/Q 控制已撤销，不用于新版交互验收。
- `node export-check.mjs`：真实点击导出，并用 GLTFLoader 重载验证完整几何和包围盒。
- 当前截图与检查报告见 [交互修复与水手系统验收](artifacts/interaction-20261008/final-report.md)，画面索引为 `artifacts/interaction-evidence.json`。
- 浏览器检查脚本还需要 Playwright 和 Microsoft Edge；当前电脑使用现有工具运行，这些工具不属于游戏运行依赖。

模型与纹理在本地程序化生成。高细节版本主要面向电脑；窄屏布局与触控已检查，真实手机性能未实测。
